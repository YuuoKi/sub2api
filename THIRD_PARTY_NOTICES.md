# Third Party Notices

This repository retains its original license and third-party notices for
internal review, source delivery, and compliance traceability.

## White-label demo UI

The Phase 2 customer demo mode changes only the customer-facing product
presentation for the AI video gateway workflow. It does not remove,
rewrite, or conceal the source license, upstream project notices, or
third-party obligations from the source package.

## License preservation

- `LICENSE` is kept in the repository unchanged.
- Existing upstream copyright and attribution information are retained.
- The customer demo package intentionally omits detailed open-source
  license text because it is a sanitized product demonstration artifact,
  not a source distribution package.
- Internal review packages keep the compliance reminder that white-label
  customer UI does not mean the codebase is represented as fully original
  source code.

## Delivery guidance

Before any formal commercial delivery, perform a legal and compliance
review of the final packaging, license notices, attribution placement,
and distribution model.
