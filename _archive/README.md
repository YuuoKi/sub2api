1. 先读根目录 `00_START_HERE.md`。
2. 再读 `docs/CHAT_STRATEGY_CONTEXT.md`。
3. 最后读 `docs/reviews/LATEST_REVIEW_PACKAGE.html` 获取最新验证证据。
