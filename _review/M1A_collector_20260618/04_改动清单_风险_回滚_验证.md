## 风险 + 回滚
| 风险 | 缓解 / 回滚 |
|---|---|
| 拖垮/搞坏主路由（基准4） | 限容+fail-open+不复用池缓冲；`enabled` **默认 false**，回滚=翻开关，无需改 schema |
| 高并发内存 | 硬 cap（写满即停），上界 `并发×cap`；prompt 本就在内存；sink 持独立 buffer |
| 脱敏漏判（合规，基准3） | 入库前脱敏 + `redaction_version` + 保留期清理（仿 `usage_cleanup_task`/`migrations/042`，**M1 跟进项**） |
| 新表/迁移影响现有写入 | 纯增量旁路表，不动 usage_logs；回滚=drop 表 + 还原代码 |
| request_id 空/复用 | partial 唯一索引 + `ON CONFLICT DO NOTHING`；空 request_id 不可去重（已知小量缺口） |
| 池化缓冲 use-after-return | sink 必须新 `[]byte`，禁用 `getSSEScannerBuf64K`(`gateway_service.go:7180`) |

## 验证（M1-B 施工后，不真实调用/不碰真库）
- **脱敏单测**（仿 `logredact`/`content_moderation_redact`/`video_gateway_redact` 表驱动）：access_token/password/Bearer/JWT/长 hex 被剥；新 `redactPII` 剥 email/电话且不误伤 model 名/UUID。

- **迁移测试**：跑 `140` 断言表+唯一索引存在、`ON CONFLICT DO NOTHING` 幂等。
