## 目标

修复线上密钥库 HC-ATOM 图片账号录入流程，使管理员可以正确完成：

- 识别并复用已有图片分组，不再出现“分组不可见但名称已存在”；
- 必要时可靠创建图片分组，重复点击或并发请求不会出现重复英文错误；
- HC-ATOM（图片）只展示并保存已授权的 5 个图片模型；
- 账号、分组、图片价格、员工 media Key 与 QCanvas 模型目录形成真实可验收闭环；
- 修复后提交、部署，再通知用户进行一次最小真实测试。

授权图片模型固定为：

1. `seedream-5.0`
2. `doubao-seedream-5.0-pro`
3. `gemini-3.1-flash-image-preview`
4. `gpt-image-2`
5. `s-gpt-image-2`

`dola-seedream-5.0-pro`、文字模型和视频模型不得进入该图片账号目录。

## 硬边界

- 不读取、打印或提交上游 Key、token、cookie、生产连接串；
- 本轮工程验收不触发真实付费 provider 调用；
- 不静默回退官方平台或其他模型；
- 不删除生产数据、卷、备份或历史回滚镜像；
- 不修改 QCanvas 用户操作契约，除非审查证明现有契约无法完成图片闭环。

## 验收

1. 截图问题可稳定复现，并由前后端测试覆盖；
2. 已有同名分组可选择或得到明确中文提示，不再重复 toast；
3. HC-ATOM 图片录入弹窗只显示 5 个授权图片模型；
4. 账号保存后，分组、权限、价格和模型映射一致；
5. 员工 media Key 的 `GET /v1/models?kind=image` 只返回这 5 个模型；
6. QCanvas 图片模型目录只采用 Sub2 返回值，未登录和未授权时失败关闭；
7. 后端定向测试、前端定向测试、类型检查、构建与 `git diff --check` 通过；
8. 更新 `docs/reviews/LATEST_REVIEW_PACKAGE.html`，提交后受控部署并复核线上版本；
9. 只有生产账号、分组、员工 media Key 与目录证据齐全后，才通知用户进行付费实测。
