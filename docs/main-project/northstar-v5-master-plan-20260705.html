North Star

继承 V2→V3→V4：为什么做、服务谁、两仓为什么不能混

无界互娱的主线不是做一个 AI 视频演示，而是做 AI 中短剧 / 漫剧生产公司 + AI 生产工具公司。系统价值不是卖 token，而是把散落的 AI 账号、员工生产、结果资产、成本与经验沉淀成可管理、可记录、可复用、可商业化的生产飞轮。V5.0 首次可以宣称：这个飞轮的"管钱"一环已经真实转动。

一句话商业定位（V2/V3 至今不变）：帮 AI 内容公司把 N 个上游密钥/账号收敛成一条受控 API，把员工生产经验沉淀成可复用 skill 的企业级管理系统。我们不卖 token，卖「管住 AI 生产」。

三柱价值（V2 起源 · 202606）

资产侧 · N 账号 → 一条 API

即梦 / 可灵 / NanoBanana / GPT-Image / Seedance 等多 provider、多账号、含逆向与负载均衡，统一收敛为一条出口；按员工/工具身份开卡，调用数据回收归总。Sub2API 侧调度与计费 V5.0 已真实验证（R2-A）。

经验侧 · 每次生产 → skill

prompt、参数、用图、结果、成本、采用信号全量采集（ai_generation_content 已在真实链路运行）；skill 草稿与人审仍 已冻结，等两周真实账本稳定。
