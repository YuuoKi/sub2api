目标

  • 让 ai_generation_content 进入内部日常账本：能按视频任务写入采纳状态、质量分、备注。
  • 增加周报聚合：条目数、视频任务数、成本估算、采纳/拒绝/待处理/未复核、异常计数与 Markdown 摘要。
  • 让管理员在现有 Generation Content 页面看到周报，并能在样本卡片上提交采纳反馈。
  • 保持真实供应商调用与真实出片 已冻结，本轮只做本地代码、测试与构建。

背景

Phase A' 已经证明 Tiny Real 三证链路。本阶段不再真出片，而是把已采集的生产内容与视频任务编号、成本估算、采用反馈连接起来，服务老板/员工/技术管理员的内部复盘。

本轮没有引入租户模型、供应商真实调用、外部发布或公网暴露。

实现细节

  • 采纳反馈以 task_id 为业务键写入 ai_generation_content，不新增账号、租户或商业化模型。
  • 接口允许状态 adopted、rejected、pending，质量分范围为 0..1，备注最多 2048 字符。
  • 采集开关未启用时，采纳接口返回 enabled:false、saved:false，避免误判为已写入。
  • 周报聚合使用 ai_generation_content 左连接 video_tasks，统计失败任务、缺失任务关联和截断行，便于后续运营复盘。
  • 前端沿用现有 StatCard 与内容墙，不新增独立导航或大范围 UI 重构。
