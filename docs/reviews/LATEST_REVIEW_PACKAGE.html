实现与安全边界

  • 目录只公布 5 个可执行模型；Dola 不进入公开模型目录，也不能进入调度缓存。
  • 通用 HC 账号映射保持 3 个文字模型与这 5 个图片模型；Dola 不进入账号能力映射。
  • 同步模型自动规范化 prompt / count / quality / reference_images；Seedream 只接受文生图，Doubao 支持参考图。
  • 异步模型使用平铺请求体，支持 1K/2K/4K、比例、参考图；GPT 两个模型会把档位换算为真实上游像素，且 4K 严格低于上游像素上限。
  • GPT 两个模型使用 x-api-key，Gemini 使用 Bearer；支持 queued/running/success/failed/cancelled 与结果 URL。
  • 安全的 failReason 可回传，当前解密 Key、疑似密钥或签名 URL 会被脱敏；无静默官方回退。
  • 单任务、单输出、模型、比例或协议不完整时，在账号选择、解密、计费和网络请求前失败。
