风险与回滚

  • 未执行 fetch，远端跟踪 refs 不是远端服务器实时证明；本轮明确不清理远端分支。
  • 没有执行真实供应商 E2E、生产部署或线上回归；本审查包只证明本地分支收口和工程门禁。
  • Windows 首次删除临时 HC worktree 时触发长路径错误；Git 注册已移除，剩余目录经精确路径清理。其余旧目录仅残留被忽略的 node_modules，确认无源码/WIP 后删除。
  • 回滚锚点：archive/pre-consolidation-main-20260730 → 原 main，archive/runtime-billing-blockers-20260725 → 原计费旁支。
  • 禁止 reset/clean/rebase；需要回滚时使用 git revert 撤销合流或文档提交。
