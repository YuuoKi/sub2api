风险、阻塞与下一步

  • 生产尚未配置媒体凭证专用 32-byte hex 加密 Key，HC 媒体账号暂不能保存；不得临时生成或复用视频/JWT Key。
  • 文字模型只有配置 Channel token 价格后才展示；图片/视频要求各自组价格为正。
  • 真实 HC 的成功/失败响应和资产下载尚未付费验证，不能标记产品 READY。

回滚：将服务镜像恢复到部署前保留的 rollback 标签并仅重建 Sub2API；数据库无新增迁移。功能开关保持关闭时，新链不会产生上游请求。
