目标与合同

管理员为同一 Sub2API user 原子签发两张逻辑 Key：video 绑定视频路由组，media 绑定 LLM/图片路由组。两个 group_id 必须不同且可用；两张 Key 共用同一用户余额，消费继续按 user_id 汇总。保留原单 Key 开卡。

实现

层事实
后端接口POST /api/v1/admin/users/:id/qcanvas-key-pair；独立幂等作用域；首次返回两把明文，重放只返回脱敏元数据。
事务repository 在一个 Ent 事务内创建 video/media 两条记录；第二条失败时整体回滚。
校验用户存在、两个 group_id 为正且不同、组存在/启用、用户可绑定。
员工页新增 QCanvas 双 Key 入口、两组选择、首次复制与关闭即清空；卡名显示逻辑角色与实际组。
计费未新增余额或第二账本；员工总览继续读取 user 聚合成本，两张 Key 的消费合并。
