## 1. 目标

- 为视频创建接口补齐 `content[]` 输入契约，支持 `text`、`image_url`、`video_url`、`audio_url` 及角色字段。
- 给 `video_tasks` 增加 JSON 内容列，持久化 content 数组，并补充 `has_video_input`。
- 保持旧字段 `reference_image_url` / `reference_video_url` 向后兼容。
- 增加顶层布尔参数 `generate_audio`、`watermark`、`camera_fixed`、`return_last_frame`。
- 校验图片/视频/音频数量、图片模式互斥、URL SSRF/allowlist、Seedance 分辨率与时长边界。
- 不修改 `frontend/**`，不做真实 provider 调用，不读取 `.env` / key / token / cookie。

## 5. 风险

- `content[]` URL 校验复用现有 `validateExternalVideoURL`，会受 `SUB2API_VIDEO_URL_ALLOWLIST` 影响；生产 allowlist 需要覆盖实际媒体来源域名。
- 当前 Seedance single smoke gate 仍保留 1-5 秒限制；A-1 创建校验按任务书为 `-1` 或 4-15 秒。真实 single smoke 仍只能走两者交集，当前测试使用 5 秒。
- migration schema 集成测试因本地缺少可用 integration DB 未完成，需要在有测试 DB 的环境复跑。
- 本轮只补齐 A-1，不处理 A-2 响应契约、V-2 到 V-5 计费补齐或 A-4 收口。
