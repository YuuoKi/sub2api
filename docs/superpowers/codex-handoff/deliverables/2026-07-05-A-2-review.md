## 1. 目标

- 从 Seedance/Ark 轮询成功响应提取并落库：
  - `usage.total_tokens`
  - 上游确认的实际分辨率 `actual_resolution`
  - 上游确认的实际时长 `actual_duration`

- `GET /v1/video/tasks/:id` 响应新增 `usage`、`actual_resolution`、`actual_duration`、`last_frame_url`、`has_video_input`。

## 5. 风险

- `usage.total_tokens` 依赖真实 Ark poll 响应字段；本轮用本地 HTTP fixture 验证解析，未做真实 provider 调用。
- `last_frame_url` 走 allowlist 校验；生产环境需要确保 Ark CDN / 尾帧域名在 `SUB2API_VIDEO_URL_ALLOWLIST` 内。
- API-key 响应已移除 `ResultURL`，若前端仍读 PascalCase 会拿不到；应同步只读 `result_url`。
- A-2 只落库真实 token，为后续 BILLING V-2 提供依据；实际视频计费切换不在本轮完成。
