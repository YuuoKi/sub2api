## 目标

按 `docs/superpowers/codex-handoff/CODEX_TASK_API_CONTRACT.md` 的 A-3 要求补齐 Gemini 图片调用契约：

- Claude 兼容请求中的 `imageConfig`、`responseModalities` 透传到 Gemini `generationConfig`。
- Claude image URL source 转换为 Gemini `fileData`，并复用既有外部 URL SSRF/allowlist 校验。
- `imageSize` 支持 `512`、`512px`、`0.5K` 映射为 `0.5K`；未知尺寸默认 `2K` 并记录 warning。
- 图片响应计费数量不再固定为 1，而是按 Gemini 响应内实际 `inlineData` 图片 part 计数。
- native passthrough 过滤空 parts 时保留 `thoughtSignature`。

## 风险

- `source.type=url` 当前选择 Gemini `fileData` 转发，不在后端下载外部图片；因此不引入后端出网下载链路，但依赖上游对 `fileData.fileUri` 的支持。
- URL 校验复用现有 `validateExternalVideoURL`，会受 `SUB2API_VIDEO_URL_ALLOWLIST` 影响；若生产设置 allowlist，Gemini image URL source 也会按该 allowlist fail-closed。
- streaming 多图计数按收到的 `inlineData` part 累加；如某上游以累计重复事件重放同一图片，可能重复计数，需要真实 provider 证据复核。本轮未做真实 provider 调用。
