## 8. 给 Claude 的前端接口说明

- 视频接入方继续读取 `id`、`status`、`result_url`、`error_message`、`provider`；不要读取 `ResultURL`。
- 新视频创建 UI 应提供 `content[]` 编辑能力，并按 `text_to_video` / `image_to_video` / `reference_to_video` 模式限制 role 组合。
- 续拍链路：创建任务传 `return_last_frame=true`，轮询成功后读 `last_frame_url`。
- 视频费用展示可使用 `usage.total_tokens`、`has_video_input` 与 V-3/V-4 的统一花费字段，币种折算以后端输出为准。
- 图片 UI 建议只暴露 `512`、`1K`、`2K`、`4K` 四档，NB2 计费分别为 `$0.045`、`$0.067`、`$0.101`、`$0.151` 每图。
- 多图输出不要假设固定 1 张，应按响应实际 `inlineData` 图片 part 展示、下载和复用。
