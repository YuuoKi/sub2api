## 1. 目标

- 用任务书内已核实的 Seedance 官方 CNY 价格补齐视频计费，不上网查价。
- Seedance 成功任务优先使用 Ark poll 回传的 `usage.total_tokens` 计费：`tokens / 1,000,000 * 元/M tokens`。
- Seedance 失败任务费用为 0。
- 创建前预算 gate 不再默认为 0，按任务书给出的每秒参考价估算。
- 本轮只做 V-2：不新增币种、`pricing_source`、`pricing_version` 落库字段，这些留给 V-3。
- 不修改 `frontend/**`，不做真实 provider 调用，不读取 `.env` / key / token / cookie。

## 2. 变更清单

- `backend/internal/service/video_gateway_pricing.go`
  - 新增视频价格目录 `VideoPricingCatalog`，支持默认内置价格与运行时 override。
  - 内置 Seedance 价格：
    - `doubao-seedance-2.0`：无视频输入 46.00 元/M tokens；有视频输入 28.00 元/M tokens。
    - `doubao-seedance-2.0-fast`：无视频输入 37.00；有视频输入 22.00。
    - `doubao-seedance-1.5-pro`：有声 16.00；无声 8.00。
    - `doubao-seedance-1.0-pro`：15.00。
    - `doubao-seedance-1.0-pro-fast`：4.20。
    - `doubao-seedance-1-0-lite`：10.00。
  - 模型匹配兼容 `.` / `_` / `-` 变体，优先匹配更长规则。
- `backend/internal/service/video_gateway_service.go`
  - `VideoGatewayService` 初始化默认视频价格目录。
- `backend/internal/service/video_gateway_billing.go`
  - 新增 Seedance 成本计算：成功任务按 `usage.total_tokens` 计真实费用。
  - `chargeForVideo` 从空记账改为使用真实费用；失败任务记 0。
  - 预算估算在未配置 `CostPerSecond` 时使用任务书参考价：
    - Seedance 2.0：480p 0.5 元/s，720p 1.0 元/s，1080p 2.5 元/s。

  - terminal 成功时把 Seedance `actual token cost` 写回 `VideoTask.CostEstimate`，并同步进入 `video_usage_logs.cost_estimate`。
  - terminal 失败时费用写 0。
- `backend/internal/service/video_gateway_billing_test.go`
  - 新增 Seedance token 计费、视频输入档位、失败不计费、预算参考价测试。

## 4. 验收点

- mock Seedance 成功任务 `usage.total_tokens=102960`、无视频输入、`doubao-seedance-2.0` 时：
  - 费用为 `46 * 0.10296 = 4.73616` CNY。
  - `video_usage_logs.cost_estimate` 同步为 `4.73616`。
  - `Charge` 使用同一费用值。
- 同一 token 量但 `has_video_input=true` 时使用 28 元/M tokens，费用为 `2.88288` CNY。
- 失败任务即使 mock adapter 返回 token 和 result_url，落账费用仍为 0。
- 未配置 `CostPerSecond` 时，720p 5s Seedance 2.0 预算估算为 5.0 CNY；Fast 720p 5s 为 4.0 CNY。
