## 1. 目标

- 给 `usage_logs` 与 `video_usage_logs` 补齐对账字段：`currency`、`pricing_source`、`pricing_version`。
- 将 `ResolvedPricing.Source` 从内存计算链路落到 `usage_logs.pricing_source`。
- Seedance 视频费用落库时标记 `currency=CNY`、`pricing_source=provider_usage`、`pricing_version=ark-seedance-2026-03`。
- 新增管理员可配置系统设置 `usd_cny_rate`，默认 `7.20`，不接入任何自动汇率 API。
- 提供 USD/CNY 汇总换算 helper 与单测；视频费用并入 dashboard 归总留给 V-4。
- 不修改 `frontend/**`，不做真实 provider 调用，不读取 `.env` / key / token / cookie。

## 4. 验收点

- `usage_logs` insert / batch / best-effort / scan 参数包含 `currency`、`pricing_source`、`pricing_version`。
- usage log 缺省对账字段兼容旧调用：`USD / fallback / NULL`。
- `OpenAIGatewayService.RecordUsage` 与 `GatewayService.buildRecordUsageLog` 能把计费来源落入 usage log。
- Seedance terminal 任务写 `video_usage_logs` 时标记：
  - `currency=CNY`
  - `pricing_source=provider_usage`
  - `pricing_version=ark-seedance-2026-03`
- 管理设置可读写 `usd_cny_rate`，默认值为 `7.20`，无自动汇率 API。
- 换算 helper 覆盖：
  - `CNY -> USD`：金额除以汇率。
  - `USD -> CNY`：金额乘以汇率。
  - 同币种不变。
  - 无效汇率不改变金额。

## 6. 风险

- 本轮没有真实 provider 调用；Seedance metadata 依赖本地 worker/cancel/fail/terminate 单测路径与 mock repository 验证。
- V-3 已提供统一换算能力与设置，但没有把视频费用并入 dashboard；该归总展示按任务书留给 V-4。
- 迁移使用默认值补历史数据：旧 `usage_logs` / `video_usage_logs` 会被标记为 `USD/fallback`，真实历史视频币种如需精确回填，需要单独数据修复脚本，当前未做。
