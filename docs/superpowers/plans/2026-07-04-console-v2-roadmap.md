## 现状评估（一句话版）

管控闭环已经齐了：**密钥收进来 → 给员工开卡 → 调用被记录 → 总览看钱**。
但商用价值兑现卡在一件事上：**真实生成通道（Seedance / Kling）还没接通**，目前全链路是演示通道验证的。P0 只有一个主题：让真钱真任务跑起来，并且钱算得准。

## P0 —— 商用兑现（不做这些，系统只是漂亮的壳）

### P0-1 真实视频通道接通【老板 + Codex】

- 老板提供 Seedance（火山方舟）真实 API Key，录入密钥库 → 视频供应商。
- Codex：核对 `SUB2API_VIDEO_URL_ALLOWLIST` 白名单、`VIDEO_GATEWAY_PER_CALL_BUDGET` 单次预算上限，跑一条最小成本真实任务（后端已有 `SUB2API_VIDEO_REAL_SMOKE_ENABLED` 冒烟开关）。
- 验收：真实任务成功回收视频，任务记录出现真实 result_url，费用入账。

### P0-2 视频计费从"估算"变"对账"【Codex】

- 现状：`video_tasks.cost_estimate` 是估算值，不是供应商实际扣费。
- 任务：按 Seedance 官方计价（分辨率 × 时长 × 模式）实现计费表，任务回收时写入实际费用；月底能和供应商账单对上。
- 涉及：`backend/internal/service/video_gateway_service.go`、`video_usage_logs`。
- 验收：同一条任务，控制台显示费用与供应商后台账单一致（±1%）。

### P0-3 外部工具归属修正【Codex 后端 + 前端-Claude】

- 问题：现在"外部工具接入"复用 `/keys` 页面，管理员在这里建的密钥全部挂在管理员本人名下，工具的消费会被算成管理员的消费，污染"谁花了多少钱"。
- 方案：把"外部工具"变成一种特殊成员——为每个工具（n8n、剪辑脚本、批量出图器）创建一个"工具账号"（users 表普通用户，notes 标注"工具"），用现成的开卡接口发 Key。
- 后端【Codex】：users 增加可选标记（用现有 user_attributes 即可，不动表结构），或约定 notes 前缀 `[工具]`。
- 前端【前端-Claude】："员工与开卡"页改名"成员与开卡"，增加"新增工具"入口（和新增员工同一弹窗，类型切换）；"外部工具接入"导航项移除或改为跳转说明页。
- 验收：总览员工排行里工具和人分开显示，消费归属互不污染。

### P0-4 通道异常上浮到总览【前端-Claude】

- 老板不该主动去看"生成通道"页。当任意启用中的通道凭证异常/鉴权失败时，总览顶部显示一条红色警示："Seedance 凭证鉴权失败，新任务会失败 → 去密钥库检查"，点击直达密钥库对应标签。
- 数据源：`/admin/video/dashboard` 的 `health_diagnostics` 已有全部所需字段，纯前端工作。

## P1 —— 管钱管人（商用一两周内就会需要）

### P1-1 预算与告警【Codex 后端 + 前端-Claude】

- 员工卡已支持额度（quota），缺的是"快用完时有人知道"。
- 后端：卡额度使用率超过 80% / 100% 时产生通知事件（复用现有通知邮箱体系 `balance_notify_*` 的基础设施）。
- 前端：员工与开卡列表中额度接近用尽的卡标黄/标红；总览显示"本月预算使用进度条"（老板设一个月度总预算数字，存 settings）。
- 验收：卡花到 80% 老板能在总览看到黄条提醒。

### P1-2 员工 skill 系统一期：提示词沉淀看板【前端-Claude，后端已现成】

- 后端已有但前端没暴露的能力：
  - `POST /admin/generation-content/:task_id/adoption`——给某次生成标"采纳/拒绝/待定 + 质量分 + 备注"
  - `GET /admin/generation-content/weekly-report`——自动生成周报（含采纳率、异常统计、markdown）
- 前端：在"任务记录 → 提示词采集"里给每条样本加"采纳 / 拒绝"按钮和质量评分；新增"经验周报"入口渲染 weekly-report 的 markdown。
- 价值：这就是老板要的"员工经验总结"最小闭环——好提示词被标出来，周报自动汇总。
- 验收：标记 3 条样本后，周报里能看到采纳率变化。

### P1-3 成品素材库【Codex 后端 + 前端-Claude】

- 问题：生成的视频现在只有一个 `result_url` 链接，上游链接会过期，没有归档。
- 后端【Codex】：任务成功后异步把结果文件落到本机 `/app/data/assets/`（或老板指定的 NAS 路径），记录本地路径；加过期清理策略。
- 前端【前端-Claude】：新导航项"成品库"：按员工 / 日期 / 剧目筛选的视频卡片墙，支持预览和下载。
- 验收：上游链接过期后，成品仍能在成品库播放。

### P1-4 总览下钻【前端-Claude】

- 员工排行点击某员工 → 直接跳到"AI 调用记录"并自动带上该员工筛选（现在只是跳员工与开卡页）。
- 模型分布环形图点击某模型 → 同理带模型筛选。
- 纯前端，半天工作量。

## 明确不建议做的

- **不要给员工开放完整标准模式后台**——标准模式几十个菜单是给 API 中转站运营者的，员工只需要：试跑/提交任务 + 自己的卡。
- **不要现在做多租户/多公司**——单公司内部工具，加租户只会拖慢一切。
- **不要把"生成通道"页暴露给老板日常使用**——它是技术页，老板的入口是密钥库 + 总览警示条（见 P0-4）。
